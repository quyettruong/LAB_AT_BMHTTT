# LAB1.2 — Bảo mật Telnet – SSH

## Thông tin sinh viên

- Họ và tên sinh viên: Trương Văn Quyết
- Mã số sinh viên: 1150080155
- Tên bài Lab: Bảo mật Telnet – SSH
- Nội dung đã thực hiện: Thiết lập mô hình gồm Ubuntu Server, Kali Linux và Windows Client. Cấu hình dịch vụ Telnet và SSH trên Ubuntu, sử dụng PuTTY để kết nối từ Windows và Wireshark trên Kali để bắt, phân tích các gói tin Telnet/SSH.
- Kết quả thực hiện: Kết nối Telnet và SSH thành công. Qua Wireshark nhận thấy Telnet có thể để lộ thông tin đăng nhập và nội dung trao đổi ở dạng rõ, trong khi SSH mã hóa dữ liệu nên không thể đọc trực tiếp username, password và các lệnh đã thực hiện.
