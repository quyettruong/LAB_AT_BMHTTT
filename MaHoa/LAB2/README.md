# LAB 2 — Mã hóa đối xứng hiện đại (Java Swing – Maven – Microsoft SQL Server – Python)

## Thông tin sinh viên

- Họ và tên sinh viên: Trương Văn Quyết
- Mã số sinh viên: 1150080155
- Lớp: 11_ĐH_THMT
- Tên bài Lab: LAB 2 — Mã hóa đối xứng hiện đại (Java Swing GUI Builder – Apache Maven – Microsoft SQL Server – Python Tkinter)
- Nội dung thực hiện: Khởi tạo dự án Maven `LAB2_MaHoaHienDai` trên NetBeans 25, cấu hình `pom.xml` sử dụng Java 17, nạp các thư viện `mssql-jdbc:12.8.1.jre11` và `bcprov-jdk18on:1.78.1` (BouncyCastle), xây dựng các lớp tiện ích `CipherUtil` (chuyển đổi UTF-8, Base64, HEX, sinh số ngẫu nhiên an toàn SecureRandom, dẫn xuất khóa PBKDF2) và `FileTextIO` xử lý nạp/xuất tệp văn bản. Thiết lập cơ sở dữ liệu `LAB2_MaHoaHienDai` trên Microsoft SQL Server Express qua TCP/IP cổng 14333, tạo tài khoản `lab2_user`, bảng người dùng `dbo.app_users` và bảng lịch sử `dbo.crypto_history`. Xây dựng các lớp truy xuất dữ liệu `DbConfig`, `HistoryDao`, `UserDao` (mã hóa mật khẩu bằng PBKDF2 với 120.000 vòng lặp kết hợp salt ngẫu nhiên 16 byte, cấp Ticket phiên làm việc 128-bit) cùng các form `frm_KetNoiSQL` và `frm_LichSu` hiển thị qua `JTable`. Cài đặt và thiết kế giao diện đồ họa JFrame Form cho 5 thuật toán đối xứng hiện đại: DES (khối 64-bit, mode CBC + PKCS5Padding, IV 8 byte), TripleDES (khóa 24 byte, chạy 3 lần DES), AES-GCM (khóa 256-bit tạo từ mật khẩu bằng PBKDF2, nonce 12 byte, thẻ tag 16-bit xác thực toàn vẹn, tích hợp phân quyền Register/Login), RC4 (mã dòng KSA + PRGA, xuất bản mã dạng HEX) và Twofish (dùng BouncyCastle, CBC mode, IV 16 byte lưu kèm bản mã). Thực hiện 2 bài nâng cao: AES-256 chế độ CTR trên Java (`AESCTRCipher`, `frm_AES_CTR` biến mã khối thành mã dòng không cần đệm, sinh cặp Key/Nonce ngẫu nhiên) và AES-256 chế độ CBC bằng Python Tkinter (`aes_cbc_gui.py` dùng thư viện `cryptography`, đệm PKCS7, hỗ trợ cờ tự kiểm thử `--self-test`). Cuối cùng, hoàn thiện menu chính `frm_Menu` điều hướng trung tâm kết nối toàn bộ hệ thống chương trình.
- Kết quả thực hiện: Toàn bộ dự án biên dịch thành công (`BUILD SUCCESS`), kiểm thử chính xác 100% các bộ dữ liệu mẫu theo yêu cầu: DES giải mã hoàn hảo câu tiếng Việt "Xin chào Lab 2 - Mã hóa hiện đại!" với khóa 8 byte `12345678` (IV sinh ngẫu nhiên làm thay đổi bản mã mỗi lần mã hóa, bẫy lỗi khi nhập khóa sai 87654321 hoặc sai độ dài); TripleDES mã hóa/giải mã chính xác với khóa 24 byte và bẫy lỗi khi thiếu ký tự; AES-GCM đăng ký và đăng nhập thành công tài khoản `sinhvien01`, cấp Ticket 32 ký tự HEX, mã hóa/giải mã toàn vẹn với mật khẩu `MatKhauAES@2026` và tự động kích hoạt ngoại lệ `AEADBadTagException` phát hiện ngay khi bản mã bị can thiệp sửa đổi 1 bit; RC4 mã hóa đúng chuỗi HEX chuẩn `BBF316E8D940AF0AD3` từ Plaintext/Key; Twofish sinh IV 32 ký tự HEX, lưu và khôi phục thành công cả IV và bản mã từ tệp `twofish_ciphertext.txt`; AES-CTR mã hóa/giải mã văn bản dài > 1000 ký tự mà không thay đổi độ dài chuỗi; chương trình Python AES-CBC vượt qua toàn bộ 4 bài test trong chế độ `--self-test` in `SELF-TEST OK` và giao diện Tkinter hoạt động mượt mà. Kết nối thông suốt SQL Server qua cổng 14333, tự động ghi nhận nhật ký các thao tác REGISTER, LOGIN, ENCRYPT, DECRYPT và hiển thị trực quan lên `JTable` cũng như truy vấn SSMS, hoàn thành trọn vẹn yêu cầu bài thực hành.
