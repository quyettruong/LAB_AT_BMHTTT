# LAB 1 — Mã hóa đối xứng cổ điển (Java Swing – Maven – Microsoft SQL Server)

## Thông tin sinh viên

- Họ và tên sinh viên: Trương Văn Quyết
- Mã số sinh viên: 1150080155
- Lớp: 11_ĐH_THMT
- Tên bài Lab: LAB 1 — Mã hóa đối xứng cổ điển (Java Swing GUI Builder – Apache Maven – Microsoft SQL Server)
- Nội dung thực hiện: Khởi tạo dự án Maven `LAB1_MaHoaCoDien` trên NetBeans 25, cấu hình `pom.xml` sử dụng Java 17 và nạp thư viện `mssql-jdbc:12.8.1.jre11`, xây dựng lớp tiện ích `FileTextIO` đọc/lưu file text UTF-8. Thiết kế giao diện đồ họa JFrame Form và cài đặt thuật toán cho 6 phương pháp mật mã cổ điển: Caesar, Vigenère, Rail Fence, Playfair, Transposition (hoán vị cột) và Autokey, có đầy đủ chức năng Encrypt, Decrypt, Open File, Save File và bẫy lỗi dữ liệu nhập. Thực hiện bài nâng cao 01: cấu hình dịch vụ Microsoft SQL Server Express 2025 qua TCP/IP cổng 14333, tạo tài khoản `lab1_user`, cơ sở dữ liệu `LAB1_MaHoaCoDien` và bảng `dbo.history`, xây dựng các lớp `DbConfig`, `HistoryDao` dùng `PreparedStatement` chống SQL Injection, cùng form kết nối `frm_KetNoiSQL` và xem lịch sử `frm_LichSu` qua `JTable`. Thực hiện bài nâng cao 02: xây dựng lớp `AttackDemos` và form `frm_TanCong` triển khai 3 kỹ thuật thám mã cổ điển gồm vét cạn Caesar (Brute Force 26 khóa kết hợp chấm điểm tần suất tiếng Anh), phân tích tần suất chữ cái (Frequency Analysis) và tấn công khi biết trước bản rõ (Known Plaintext Attack). Cuối cùng, thiết kế form menu chính `frm_Menu` điều hướng trung tâm kết nối toàn bộ các form chức năng của chương trình.
- Kết quả thực hiện: Toàn bộ dự án biên dịch thành công (`BUILD SUCCESS`), kiểm thử chính xác 100% các bộ dữ liệu mẫu theo yêu cầu: Caesar (`HELLO` với khóa 3 $\rightarrow$ `KHOOR`), Vigenère (`HELLO` với khóa KEY $\rightarrow$ `RIJVS`), Rail Fence (`HELLO WORLD` với khóa 3 $\rightarrow$ `HOREL OLLWD`), Playfair (`HELLOWORLD` với khóa KEYWORD $\rightarrow$ `GYIZSCOKCFBU`), Transposition (`BAOMAT` với khóa 2,3,1 $\rightarrow$ `AAOTBM`) và Autokey (`HELLO` với khóa KEY $\rightarrow$ `RIJSS`). Kết nối thành công tới Microsoft SQL Server qua cổng 14333, tự động ghi nhận và hiển thị đầy đủ lịch sử mã hóa/giải mã lên `JTable` và SSMS. Thực nghiệm phân tích mật mã chính xác: vét cạn tìm đúng khóa Caesar $k=3$ cho bản rõ có nghĩa nhất, phân tích tần suất xác định đúng chữ cái xuất hiện nhiều nhất và giải ngược thành công khóa Vigenère `KEYKE` khi biết trước cặp bản rõ/bản mã. Menu chính mở độc lập các form chức năng mà không làm tắt chương trình, hoàn thành trọn vẹn báo cáo minh chứng và video thực hành.
